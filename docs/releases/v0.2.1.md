# Sony Headphones for Omarchy v0.2.1 — Hardware Alpha

This patch release polishes the compact sound-control interface, fixes the public-to-hardware volume mapping, and prepares a clean two-part distribution model for the Omarchy Marketplace and AUR.

## Highlights

- Theme-aware icons label Noise cancelling, Ambient, and Off while retaining centered, responsive control rows.
- A smaller panel footprint preserves native text/control sizing, standard scrolling, and live Omarchy palette updates.
- The normalized `0–100` volume contract now maps deterministically to Sony MDR's 31 discrete hardware levels and settles the UI to the representable value.
- The stable `sony-headphones-omarchy` AUR template packages the daemon, CLI, and systemd user service without writing to a user's home.
- The Marketplace retains ownership of the QML checkout, so native and graphical components have independent, reversible lifecycles.
- Installation, updating, uninstallation, publishing, dependency, and maintainer-note documentation is complete.

## Install

The AUR metadata is prepared but not submitted in this release. Until its listing exists, install from the public source repository:

```sh
omarchy plugin add https://github.com/VyomJain6904/sony-headphones-omarchy.git
cd "$HOME/.config/omarchy/plugins/io.github.vyomjain6904.sony-headphones"
./scripts/build.sh
./scripts/install.sh
systemctl --user enable --now sony-headphones.service
omarchy plugin enable io.github.vyomjain6904.sony-headphones --section right
```

Review the repository before enabling it because third-party QML executes unsandboxed inside Omarchy's shell.

## Upgrade from v0.2.0

```sh
omarchy plugin update io.github.vyomjain6904.sony-headphones
cd "$HOME/.config/omarchy/plugins/io.github.vyomjain6904.sony-headphones"
./scripts/build.sh
./scripts/install.sh
systemctl --user restart sony-headphones.service
```

## Compatibility and limitations

Hardware evidence remains limited to WH-1000XM5 firmware 2.5.1. Other Sound Connect-compatible MDR devices may work when they report supported capabilities, but this release does not claim them as tested.

No native binary is attached. Firmware updates, 360 Reality Audio, Sony account/cloud/location functions, factory reset, multipoint management, custom EQ bands, sleep/resume recovery, MDR v1 hardware evidence, true-wireless evidence, and long-duration soak testing remain outside this patch release.
