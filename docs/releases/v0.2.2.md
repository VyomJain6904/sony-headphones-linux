# Sony Headphones for Linux v0.2.2 — Hardware Alpha

This patch release repairs the Omarchy Marketplace publication findings and completes the desktop-independent native distribution rename.

## Highlights

- The canonical repository, CMake project, and native AUR package are now `sony-headphones-linux`.
- `sony-headphonesd`, `sony-headphonesctl`, `sony-headphones.service`, the permanent Omarchy plugin ID, and all version-1 state/command interfaces remain unchanged.
- Source `install.sh` and `uninstall.sh` manage only native user files; the optional Omarchy widget has an independent lifecycle.
- fmt is fetched and verified at its exact reviewed commit before CMake configuration, then supplied through a local FetchContent override with downloads fully disconnected.
- The README is a concise user guide with accurate AUR, source, update, and removal commands.
- A supported root Marketplace preview and automated documentation/installer lifecycle checks prevent the reported publication regressions.

## Install on Arch or Omarchy

```sh
yay -S sony-headphones-linux
systemctl --user enable --now sony-headphones.service
```

Optional Omarchy widget:

```sh
omarchy plugin add https://github.com/VyomJain6904/sony-headphones-linux.git
omarchy plugin enable io.github.vyomjain6904.sony-headphones --section right
```

Existing `sony-headphones-omarchy` AUR users should install `sony-headphones-linux`; the new package declares the old package as replaced.

## Source installation

```sh
git clone https://github.com/VyomJain6904/sony-headphones-linux.git
cd sony-headphones-linux
./scripts/build.sh
./scripts/install.sh
systemctl --user enable --now sony-headphones.service
```

Remove the native source installation with `./scripts/uninstall.sh`. Remove the Omarchy widget separately with `omarchy plugin remove io.github.vyomjain6904.sony-headphones`.

## Compatibility

Hardware evidence remains limited to WH-1000XM5 firmware 2.5.1 over Classic RFCOMM/MDR v2. The distribution rename and publication fixes do not broaden device compatibility claims.

No native binary is attached. Firmware updates, 360 Reality Audio, Sony account/cloud/location functions, factory reset, multipoint management, custom EQ bands, sleep/resume recovery, MDR v1 hardware evidence, true-wireless evidence, and long-duration soak testing remain outside this release.
