# Sony Headphones for Omarchy v0.2.0 — Hardware Alpha

This is the first source release of the capability-driven Sony Headphones bar widget and unprivileged native Linux service for Omarchy Quattro.

## Highlights

- Native Omarchy panel with live theme colors, standard scrolling, centered responsive action buttons, keyboard navigation, and an icon-only bar entry.
- WH-1000XM5 firmware 2.5.1 hardware evidence for battery, ANC/ambient, focus on voice, Speak-to-Chat, DSEE, playback, volume, connection priority, reconnect, and idle RFCOMM release.
- Native C++20 daemon and CLI with private state/socket permissions, immutable libmdr/fmt source pins, and no Python, Electron, root service, telemetry, or second Quickshell process.
- Correct ambient/volume slider commits that retain the final dragged value instead of reverting to the previous daemon value.
- Transport playback controls intentionally omitted from the panel; the v1 native command remains backward compatible.
- Mock, native, sanitizer, QML, manifest, install/uninstall, theme, and live-device verification documented in `docs/VERIFICATION.md`.

## Install

Omarchy clones and validates the QML plugin but intentionally does not run native build or install hooks:

```sh
omarchy plugin add https://github.com/VyomJain6904/sony-headphones-linux.git
cd "$HOME/.config/omarchy/plugins/io.github.vyomjain6904.sony-headphones"
./scripts/build.sh
./scripts/install.sh
systemctl --user enable --now sony-headphones.service
omarchy plugin enable io.github.vyomjain6904.sony-headphones --section right
```

Review the repository before enabling it because third-party QML executes unsandboxed inside Omarchy's shell.

## Compatibility and limitations

Only the WH-1000XM5 firmware 2.5.1 row in `docs/COMPATIBILITY.md` is hardware-tested. Other Sony Sound Connect-compatible MDR devices may work when they report supported capabilities, but they are not claimed as tested.

This alpha does not include firmware updates, 360 Reality Audio, Sony account/cloud/location functions, factory reset, multipoint management, custom EQ bands, or unverified controls. Sleep/resume, BlueZ restart, MDR v1 hardware, true-wireless hardware, and long-duration soak evidence remain release-follow-up work.

No native binary is attached. Build locally from the pinned reviewed sources and distribution-owned BlueZ/D-Bus libraries.
